**Краткие теоретические сведения:** 

Модуль в Python представляет собой отдельный файл с расширением .py, содержащий определения функций, переменных и классов. Модульная архитектура обеспечивает повторное использование кода и декомпозицию сложных программных комплексов. 

Импорт модулей: Для подключения встроенных или внешних модулей используется оператор import module. Для импорта конкретных функций используется форма from module import function. 

Точка входа __name__: При импорте модуля весь его код исполняется один раз. Чтобы отделить код тестирования от используемого функционала, применяется точка входа с проверкой специальной переменной if __name__ == '__main__':. 

Системный модуль sys: Модуль sys предоставляет доступ к параметрам среды исполнения. В частности, список sys.argv содержит аргументы командной строки, переданные скрипту при запуске. Python содержит четыре основные встроенные структуры данных, предназначенные для группировки и обработки наборов элементов: 

Списки (list): Упорядоченные динамические массивы элементов произвольных типов ([]). Являются изменяемыми (mutable), что позволяет добавлять (append()), сортировать (sort()) и удалять (pop(), remove(), del) элементы. 

Кортежи (tuple): Упорядоченные неизменяемые (immutable) последовательности элементов (()). Кортежи применяются для защиты данных от случайной модификации и возврата нескольких значений из функций. 

Словари (dict): Ассоциативные массивы, хранящие пары «ключ: значение» ({}). Ключи должны быть уникальными и неизменяемыми объектами (строки, числа, кортежи). 

Множества (set): Неупорядоченные коллекции уникальных элементов. Множества поддерживают математические операции: объединение (|), пересечение (&), разность (-). 

Последовательности (списки, кортежи, строки) поддерживают обращение к элементам по индексам и получение фрагментов с помощью срезов. Синтаксис среза имеет вид [start:stop:step], где start — начальный индекс (включительно), stop — конечный индекс (не включительно), step — шаг извлечения элементов.

Разворот последовательности: Срез со значением шага -1 (например, sequence[::-1]) выполняет быстрый разворот последовательности в обратном порядке. sys.argv — это специальная переменная (список строк) из системного модуля sys в языке Python, которая содержит аргументы командной строки, переданные программе при ее запуске из консоли.

# **<mark>Программный код</mark>** 

```
import LR_3_mod
step = 3
weights = [100.1, 99.5, 96.8, 101.2, 103.5, 100.0, 98.9, 100.4, 101.8]
good, bad = LR_3_mod.reject_defective_items(weights)
stats = LR_3_mod.get_weight_distribution(weights)
sample = LR_3_mod.get_sample_pack(weights, step)
print("Годная продукция:", good)
print("Брак:", bad)
print("Статистика:", stats)
print("Контрольная выборка каждого", step,"-го изделия:", sample)
def reject_defective_items(weight_list, min_w=98.0, max_w=102.0):
    good = []
    bad = []
for w in weight_list:
if min_w <= w <= max_w:
            good.append(w)
else:
            bad.append(w)
return good, bad
def get_weight_distribution(weight_list):
    stats = {"легкие": 0, "нормальные": 0, "тяжелые": 0}
for w in weight_list:
if w < 98.0:
            stats["легкие"] += 1
elif w > 102.0:
            stats["тяжелые"] += 1
else:
            stats["нормальные"] += 1
return stats
def get_sample_pack(weight_list, step=3):
return weight_list[::step]
```
